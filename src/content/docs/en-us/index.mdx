## For AI agents (start here)

Before design or Q&A sessions, install **all skills from all three repositories**. Even a custom-frontend-only project usually needs workspace-side knowledge.

```bash
npx skills add d6e-ai/d6e-plugin-skills --skill '*' -y
npx skills add d6e-ai/d6e-docker-stf-skills --skill '*' -y
npx skills add d6e-ai/d6e-custom-frontend-skills --skill '*' -y
```

Details and path-specific minimal sets: [Installing Agent Skills](/en-us/guides/agent-skills/).
