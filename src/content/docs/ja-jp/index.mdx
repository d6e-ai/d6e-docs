## AI エージェント向け（まずこれ）

設計や質問をする前に、**3 リポジトリのスキルをすべて**入れてください。カスタム FE 単体でもワークスペース側の知識が必要になることがほとんどです。

```bash
npx skills add d6e-ai/d6e-plugin-skills --skill '*' -y
npx skills add d6e-ai/d6e-docker-stf-skills --skill '*' -y
npx skills add d6e-ai/d6e-custom-frontend-skills --skill '*' -y
```

手順の詳細・パス別の最小セットは [Agent Skills の入れ方](/ja-jp/guides/agent-skills/) を参照してください。
