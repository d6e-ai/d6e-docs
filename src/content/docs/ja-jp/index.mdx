  ## AI エージェント向け（まずこれ）

  設計や質問の前に、**3 リポジトリのスキルをすべて**入れてください。カスタム FE だけでもワークスペース側の知識が必要になることがほとんどです。

```bash
npx skills add d6e-ai/d6e-plugin-skills --skill '*' -y
npx skills add d6e-ai/d6e-docker-stf-skills --skill '*' -y
npx skills add d6e-ai/d6e-custom-frontend-skills --skill '*' -y
```

  パス別の最小セットは [Agent Skills の入れ方](/ja-jp/guides/agent-skills/) を参照してください。
</div>

  <div class="build-item">
    <strong>Plugin</strong>
    <p>プロンプト・STF・ワークフローを <code>template.yaml</code> にパッケージ化し、URL または Marketplace からインストール。</p>
    <a href="/ja-jp/guides/plugins/">ガイド →</a>
  </div>
  <div class="build-item">
    <strong>Docker STF</strong>
    <p>任意言語のコンテナ。stdin/stdout の JSON 契約だけで動く可搬なビジネスロジック。</p>
    <a href="/ja-jp/guides/docker-stf/">ガイド →</a>
  </div>
  <div class="build-item">
    <strong>カスタムフロントエンド</strong>
